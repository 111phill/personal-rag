# 暖色知识工作台

## 设计依据

使用用户提供的 UI/UX Pro Max skill，对个人知识记录工具执行设计系统搜索、React 栈搜索及键盘焦点搜索。采用其简洁网格、清晰文字层级、语义颜色、可见焦点和响应式布局建议。

自动生成的配色和营销页结构不适合本项目，因此最终配色遵循用户「偏暖色一些」的明确要求，页面保留知识工作台的编辑与导航结构。此文档记录实际实现的设计决策，不是自动搜索输出。

## 视觉语言

- 奶油纸张背景、陶土橙主色、暖棕文字。
- 鼠尾草绿用于学习与记录；蜂蜜色用于思考与灵感。
- 低饱和色块、细边框和轻微投影，避免强渐变和复杂动效。
- 中文宋体用于页面主题和书写提示，无衬线中文用于操作与正文。
- 保留 Lucide 线性图标，避免引入第二套图标。

## 布局

- 桌面三栏：244px 导航、弹性编辑区、292px 辅助区。
- 1250px 以下折叠辅助区，760px 以下使用原生模态导航抽屉。
- 主编辑区最大宽度 1000px；手机横向内边距 18px。
- 每日记录：暖色页头 → 真实数据概览 → 日期切换 → 四个编辑分区。
- 收集箱、工作、学习、思考复用 SpaceHeading 与相同输入卡片。

## 交互与内容

- 保存仍复用原自动保存、版本冲突和草稿恢复逻辑。
- 日期切换仍先保存当前记录；概览只计算真实笔记内容。
- 右侧 Agent 延续纸张与陶土色系，承载对话、来源记录和服务配置状态；1250px 以下从页头按钮打开抽屉。
- 未配置模型时保留历史对话的只读入口，并明确提示配置需求。
- 模态导航支持 Escape、浏览器焦点约束及关闭后的焦点恢复。
- 保留键盘焦点、跳过导航链接、原生进度条、表单标签和保存状态播报。
- 响应系统减少动画偏好；手机删除操作不依赖鼠标悬停。
- 导出为 Markdown，不修改数据库内容。
